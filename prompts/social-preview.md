# Production Prompt: MuseAi Agent Chat social preview

Design a 1280×640 social preview for **MuseAi Agent Chat**.

## Composition

- Dark graphite-to-navy background.
- Small brand label: `MUSEAI`.
- Large title: `Agent Chat`.
- Subtitle: `Reliable delivery without a permanent connection.`
- One simple visual motif: a luminous message packet traveling from one agent node to a quiet central storage core, with a second node waiting to check in.
- Keep all important text inside a safe margin of at least 80 pixels.

## Visual language

Use a restrained cyan glow for active signal, a violet halo for depth, thin orbital lines, soft grain, and generous negative space. The image should still read when reduced to a small GitHub or social-card thumbnail.

## Do not include

Faces, stock photos, real chat content, payment logos, fake testimonials, unreadable technical tables, fake metrics, claims of encryption, or a literal “24/7 online” badge.

## Accessibility and export

Use strong contrast, avoid relying on color alone, and provide a text description alongside the asset. Export a crisp PNG or SVG at exactly 1280×640.
