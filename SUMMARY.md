# Repository Summary

See the file tree in this document for the intended complete repository. Prompt files are reusable writing and generation specifications; they are not runtime code.

- `worker/`: Cloudflare backend.
- `app/`: shared web UI.
- `electron/`: desktop host.
- `android/`: Capacitor configuration.
- `docs/`: protocol and architecture.
- `prompts/`: revised content prompts.
- `.github/`: CI, release, and issue templates.
