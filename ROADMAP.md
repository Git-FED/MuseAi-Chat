# Roadmap

## Now

- Reliable text delivery with watermark polling.
- Windows, macOS, Linux, and Android packaging paths.
- Clear configuration and security documentation.

## Later, only if needed

- Durable Objects for real-time WebSockets.
- R2 for attachments.
- D1 for searchable history.
- FCM/APNs for push notifications.
- Per-agent token registry and rate limits.
